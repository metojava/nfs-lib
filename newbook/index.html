Start here

Understand every line of a Java neural network

This book explains the actual code in this folder — Neuron, Layer, NeuralNetwork, Trainer, ActivationFunction, LossFunction, SGD, Adam, and the Fashion-MNIST downloader/loader/runner — with method-by-method documentation, parameter tables, the math behind each step, and complete code examples you can run.

What you will learn

01 · FoundationsNeuron, Layer, the neural-network constructor. 02 · Forward passHow an input becomes a prediction. 03 · BackpropagationGradients, chain rule, parameter updates. 04 · ActivationsSigmoid, tanh, ReLU, Leaky ReLU, linear. 05 · Losses & optimizersMSE, BCE, SGD, Adam. 06 · Training loopEpochs, mini-batches, shuffling. 07 · Fashion MNIST dataIDX format, normalization, one-hot. 08 · Downloader & loaderDownload from GitHub, parse IDX. 09 · Keras-like classifierFlatten → Dense(128, ReLU) → Dense(10). 10 · EvaluationAccuracy, confusion matrix, per-class. 11 · HTML reportSave results as a web page. 12 · Swing/AWT windowShow images and predictions live. 13 · Run itCompile and run with Maven/CLI. 14 · Full codeComplete listing of all classes. 15 · PracticeExercises to extend the project. Performancefloat conversion, Vector API, SIMD speedups. Projects12 standalone tutorials: XOR to GAN.

The plan

Read the code→ Understand the math→ Download Fashion MNIST→ Train the classifier→ Evaluate & report
Prerequisites. JDK 17, a text editor, and basic Java (arrays, loops, classes). You do not need TensorFlow or any ML library — everything is plain Java. Maven is optional but convenient for running the examples.
